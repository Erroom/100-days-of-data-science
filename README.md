## Session Summary

Great work today! Here is a quick recap of everything we covered:

| Concept | What You Learned |
|---------|------------------|
| Variables | Named containers to store data; use snake_case |
| Data Types | `int`, `float`, `str`, `bool`, `NoneType` |
| `type()` | Check the data type of any variable |
| Type Casting | `int()`, `float()`, `str()`, `bool()` |
| `print()` | Output data; use `sep`, `end`, f-strings, `.format()` |
| `input()` | Take user input; always returns a string |

### Things to remember:
- `input()` **always** returns a string — always cast when you need numbers
- `int(3.9)` gives `3` — truncation, not rounding
- f-strings are the cleanest way to format output: `f'Hello {name}'`
